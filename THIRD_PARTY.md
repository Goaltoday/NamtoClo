# Third-party components

## NeuralAmpModelerCore

NAM model inference uses NeuralAmpModelerCore v0.5.4, compiled into the application at build time. NeuralAmpModelerCore is MIT-licensed and includes its own third-party components under their respective licenses.

## r8brain-free-src

Sample-rate conversion uses `r8brain-free-src` (MIT), compiled into the application.

## Ooura FFT4G / SoXR source

The converter uses Takuya Ooura's FFT4G RDFT implementation from the SoXR 0.1.3 source tree, compiled directly into the application.

The corresponding upstream license files/notices should be preserved when distributing compiled builds.
